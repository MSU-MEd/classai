CURRICULUM MODULES

4 เนื้อหาหลักในการพัฒนาระบบ

จัดลำดับการเรียนรู้แบบ Workshop Step-by-Step มุ่งเน้นการลงมือสร้างสรรค์และแก้ปัญหาจริง

01
DATABASE ARCHITECTURE

การวางโครงสร้างฐานข้อมูลใน Google Sheets

เรียนรู้การจัดระเบียบตารางและฟิลด์ข้อมูลให้รองรับการเชื่อมต่อกับระบบภายนอก ทำหน้าที่เป็น Database หลังบ้านที่ปลอดภัยและตรวจสอบย้อนหลังได้ง่าย

กิจกรรม: กำหนดโครงสร้างคอลัมน์มาตรฐาน: รหัสนักเรียน, ชื่อ-สกุล, เวลาเข้าเรียน, คะแนนเก็บสะสม และสถานะส่งงาน
02
AI CODE GENERATION

การเขียน AI Prompt สั่งสร้าง Apps Script

ฝึกทักษะการสื่อสารกับ AI ด้วยเทคนิค Chain-of-Thought เพื่อให้ AI สร้างโค้ด Google Apps Script เชื่อมโยงฐานข้อมูลกับหน้าเว็บอย่างแม่นยำ

กิจกรรม: สั่ง AI ให้เขียนฟังก์ชัน doGet และ doPost จัดการรับค่าจากหน้าเว็บมาบันทึกลง Sheet โดยอัตโนมัติ
03
GITHUB PAGES DEPLOYMENT

การสร้างหน้าเว็บและโฮสต์บน GitHub Pages

สร้างหน้า Web UI สำหรับนักเรียนด้วย HTML, Tailwind CSS และอัปโหลดขึ้น GitHub Pages เพื่อเผยแพร่เป็นลิงก์เว็บไซต์ใช้งานได้ฟรีตลอดชีพ

กิจกรรม: สร้าง Repository, นำโค้ดขึ้น GitHub, เปิดใช้งาน Pages และทดสอบการเข้าใช้งานผ่านสมาร์ตโฟน
04
DEBUGGING & PDPA ETHICS

การแก้ปัญหาหน้างาน และความปลอดภัย PDPA

วิธีอ่าน Error Console และส่งโค้ดให้ AI วิเคราะห์แก้ไข พร้อมเรียนรู้หลักการจัดเก็บและแสดงผลคะแนนนักเรียนตามกฎหมาย PDPA

กิจกรรม: จำลองข้อผิดพลาดของระบบ ฝึกใช้ AI แก้ไขโค้ด และกำหนดสิทธิ์การเข้าถึงข้อมูลคะแนนส่วนบุคคล
